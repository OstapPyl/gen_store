# Gen — Інтернет-магазин генераторів для українського ринку

Повнофункціональний інтернет-магазин генераторів на стеку **Next.js 15 (App Router), TypeScript, Tailwind CSS, PostgreSQL/SQLite ORM**.

---

## ⚡ Особливості проєкту

1. **Сучасний UX/UI дизайн**:
   - Світлий фон, графітовий текст, фірмовий помаранчевий акцент енергії.
   - Чіткий каталог без нав'язливих декоративних банерів, які зсувають товари вниз.
   - Адаптивність для ПК, планшетів і смартфонів, клавіатурна навігація, коректні атрибути автозаповнення.

2. **Каталог і розширені фільтри генераторів**:
   - Сортування: спочатку нові, дешевші, дорожчі, за зростанням потужності.
   - Фільтрація: ціна (від/до), бренд (multi-select), потужність (кВт), паливо (бензин, дизель, газ, бензин/газ), інверторні, фазність (1, 3, 1/3), типи запуску (ручний, електростартер, дистанційний, ATS).
   - Додаткові характеристики: вихідна напруга (230В / 400В), **AVR** (автоматичне регулювання напруги), **можливість підключення ATS**, **наявність блока ATS у комплекті**, об'єм бака, маса, шумоізоляційний кожух, колеса.
   - Варіанти фільтрів формуються динамічно зі структурованих характеристик опублікованих товарів.

3. **Сторінка товару `/products/[slug]`**:
   - Галерея фото з мініатюрами, статус наявності, точні технічні одиниці вимірювання (кВт, В, л, кг, дБА).
   - Кнопки **«До кошика»** та швидка купівля **«Купити зараз»** без проходження кошика.
   - Комплектація, офіційна гарантія та завантаження інструкції PDF.

4. **Кошик та оформлення без реєстрації**:
   - Односторінковий чекаут, валідація українського формату телефонів (`+380...`).
   - Доставка: **Нова пошта (відділення)** з перевіркою ваги замовлення, кур’єр та самовивіз.
   - Якщо вартість доставки невідома — показується *«За тарифами перевізника, оплачується окремо»*.
   - Оплата: *«Післяплата після підтвердження менеджером»* (жодних сумнівних передоплат чи збору банківських карток).

5. **Надійна обробка замовлень**:
   - Зниження та резервування залишку в транзакції.
   - Повернення залишку на склад при скасуванні замовлення.
   - Захист від повторних запитів (ключ ідемпотентності).
   - Знімок цін, назв та артикулів у позиціях замовлення на момент купівлі.
   - Гроші зберігаються у цілих копійках.

6. **Захищена адмінпанель `/admin`**:
   - Серверна перевірка сесій (httpOnly cookie) на кожній операції, відсутність публічної реєстрації.
   - Товари: створення, редагування, чернетки, попередній перегляд, публікація, архівування.
   - Замовлення: пошук, фільтри, зміна статусів, статус оплати, поле ТТН, історія статусів, експорт в XLSX.
   - Захищений від ін'єкцій формул експорт у Microsoft Excel із текстовим форматуванням телефонів, артикулів та ТТН.
   - Налаштування магазину (назва, контакти, графік, юридичні реквізити, ключ Нової пошти).

7. **Локальна служба синхронізації на ноутбук Windows**:
   - Завантажує замовлення із сервера у локальний файл `orders.sqlite`.
   - Одностороння синхронізація через захищений токен лише для читання.
   - Робота за курсором змін, upsert без дублювання записів, стійкість до втрати інтернет-зв'язку.
   - Інструкція налаштування через Планувальник завдань Windows кожні 5 хвилин.

## 🚀 Швидкий запуск на локальному комп'ютері

1. **Встановлення залежностей**:
   ```bash
   npm install
   ```

2. **Створення файлу конфігурації `.env.local`**:
   Скопіюйте `.env.example` у `.env.local`:
   ```bash
   copy .env.example .env.local
   ```

3. **Створення першого адміністратора** (без стандартного пароля):
   ```bash
   npm run create-admin
   ```

4. **Запуск сервера розробки**:
   ```bash
   npm run dev
   ```
   Відкрийте [http://localhost:3000](http://localhost:3000) для магазину або [http://localhost:3000/admin](http://localhost:3000/admin) для адмінпанелі.

5. **Запуск наскрізної перевірки (14 етапів)**:
   ```bash
   npm run verify-e2e
   ```

6. **Локальна синхронізація замовлень на ноутбук**:
   ```bash
   npm run sync -- --once
   ```

7. **Експорт локального `orders.sqlite` в Excel (XLSX)**:
   ```bash
   npm run export-xlsx
   ```
