# Інструкція підключення та налаштування Нової пошти (API 2.0)

Інтернет-магазин **Gen** інтегрований із офіційним API 2.0 сервісу доставки «Нова пошта» для України.

---

## 1. Як отримати офіційний API-ключ

1. Увійдіть у [Бізнес-кабінет Нової пошти](https://my.novaposhta.ua/).
2. Перейдіть у розділ **«Налаштування»** → **«Безпека»** (або «Ключі API»).
3. Натисніть **«Створити ключ»**.
4. Скопіюйте згенерований 32-значний рядок.

---

## 2. Налаштування ключа в магазині

API-ключ зберігається виключно на сервері й ніколи не передається у клієнтський браузер.

Ви можете вказати його одним із двох способів:
1. **Через адмінпанель магазину**:
   - Перейдіть у розділ **/admin/settings** («Налаштування магазину»).
   - У блоці «Інтеграція з Новою поштою» введіть ключ та натисніть «Зберегти».
2. **Через змінні середовища**:
   - У файлі `.env` або `.env.local` вкажіть:
     ```env
     NOVA_POSHTA_API_KEY="ваш_32_значний_api_ключ"
     ```

---

## 3. Особливості роботи та перевірка ваги генераторів

Генератори є специфічною важкою та великогабаритною категорією товарів.
Система магазину автоматично реалізує такі захисні механізми:

- **Автокомпліт міст та селищ**: Пошук населених пунктів через метод `searchSettlements`.
- **Залежний вибір відділень**: Завантаження відділень для обраного міста через метод `getWarehouses`.
- **Перевірка вагових обмежень (`TotalMaxWeightAllowed` / `PlaceMaxWeightAllowed`)**:
  - Якщо сумарна вага замовлення перевищує ліміт відділення (наприклад, поштомат або міні-відділення до 30 кг), система блокує вибір несумісного відділення та виводить попередження:
    > *«Вага замовлення (80 кг) перевищує обмеження відділення (30 кг). Оберіть вантажне відділення.»*
  - Якщо вага генератора не вказана у картці товару, замовлення створюється з позначкою:
    > *«Маса товарів не вказана. Спосіб доставки потребує підтвердження менеджером.»*

---

## 4. Режим безпечного ручного введення (Fallback)

Якщо API Нової пошти тимчасово недоступне або API-ключ ще не внесено власником:
- Оформлення замовлень **не блокується**.
- Клієнт може ввести місто та номер відділення вручну.
- Замовлення автоматично маркується прапорцем `delivery_requires_verification = true` з поміткою «Потребує перевірки доставки», щоб менеджер уточнив сумісність відділення під час телефонного дзвінка.
