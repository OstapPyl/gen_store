# Інструкція з розгортання та хостингу інтернет-магазину Gen

Проєкт створено на базі сучасного та стабільного стеку:
- **Next.js 15 (App Router)**
- **TypeScript & Tailwind CSS**
- **База даних: PostgreSQL** (для продакшену) або **вбудована дискова SQLite** (для швидкого тестування)
- **Постійне сховище файлів (Persistent Storage)**

---

## 1. Вимоги до постійного сховища (Persistent Storage)

> [!IMPORTANT]
> Відповідно до вимог проєкту, **ніколи не використовуйте тимчасову пам'ять процесу чи ефемерну файлову систему контейнера (ephemeral storage)** без змонтованого тому для збереження замовлень та фотографій.

При розгортанні забезпечте:
1. **База даних**: Керована база PostgreSQL (Neon, Supabase, AWS RDS, Railway або окремий контейнер PostgreSQL з Persistent Volume).
2. **Директорія фотографій та інструкцій (`public/uploads`)**:
   - На VPS або в Docker: змонтуйте постійний том (volume) у директорію `./public/uploads`.
   - Змінна середовища `STORAGE_DIR="./public/uploads"` вказує шлях до сховища.
   - Дані не видаляються під час оновлення коду, перезапуску сервера чи перезбирання Docker-образу.

## 2. Змінні середовища (Environment Variables)

Створіть файл `.env` на сервері на основі `.env.example`:

| Змінна | Опис | Приклад значення |
|---|---|---|
| `DATABASE_URL` | Рядок підключення до PostgreSQL | `postgresql://user:password@host:5432/gen_store?sslmode=require` |
| `APP_SECRET` | Випадковий ключ (32+ символи) для сесій адміністратора | `openssl rand -hex 32` |
| `SYNC_API_TOKEN` | Окремий відкличний токен для читання замовлень утилітою ноутбука | `openssl rand -hex 32` |
| `NOVA_POSHTA_API_KEY` | Серверний ключ API 2.0 Нової пошти | `32-значний ключ із кабінету НП` |
| `STORAGE_DIR` | Шлях до постійної директорії для файлів | `./public/uploads` |
| `STORE_NAME` | Назва магазину | `Gen` |
| `STORE_PHONE` | Телефон магазину | `+380 44 123 45 67` |
| `STORE_EMAIL` | Email магазину | `info@gen-store.ua` |

## 3. Створення першого адміністратора

Для забезпечення безпеки **магазин не має стандартного пароля за замовчуванням**.
Перший адміністратор створюється виключно на сервері через CLI:

```bash
npm run create-admin
```
або передачею параметрів:
```bash
npm run create-admin my_admin "MyStrongPassword2026!" "Головний Менеджер"
```

Пароль надійно хешується алгоритмом `scrypt` із випадковою 128-бітною сіллю.

---

## 4. Виконання міграцій для PostgreSQL

Якщо ви використовуєте PostgreSQL у продакшені, застосуйте міграцію:
```bash
psql $DATABASE_URL -f migrations/001_init_postgres.sql
```

Усі індекси, типи, зв’язки та обмеження цілісності будуть створені автоматично.
